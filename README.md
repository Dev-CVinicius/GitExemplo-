# GitTeste

Projeto desenvolvido para prática de versionamento de código utilizando Git e GitHub no curso Técnico em Desenvolvimento de Sistemas do Senac.

## Sobre o Projeto

Este projeto foi criado com o objetivo de aprender os principais comandos do Git e o processo de sincronização entre repositório local e remoto utilizando Git Bash e GitHub.

## Tecnologias Utilizadas

- Java
- Apache NetBeans
- Git
- GitHub

## Funcionalidades

- Inicialização de repositório Git
- Controle de versões
- Criação de commits
- Sincronização com repositório remoto
- Versionamento de projeto Java
